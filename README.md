Emberlight — Keeper of the Last Lantern: a 2D canvas arena survival game. Move with WASD, aim with the mouse, hold click to shoot ember bolts, dash with Shift, survive 10 waves and banish the Hollow King.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
